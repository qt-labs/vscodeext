# Qt Bridge C# Extension Pack

This extension pack includes extensions for developing Qt Bridge for C# and
Qt Quick applications in Visual Studio Code.

You can:

- Create Qt Bridge for C# projects and QML files
- Use a Qt installation in your Qt Bridge C# project
- Get QML syntax highlighting and code completion
- Preview QML files
- Debug the QML code of Qt Bridge C# applications
- Edit, build, and debug C# code

## Get started

1. Select `Install` to install the Qt Bridge C# extension pack.
1. Go to `Command Palette`, and select `Qt: Create a new project or file`.
1. Select `Qt Bridge for C# application`.
1. Build the project once to generate the metadata required for complete QML
   Language Server and live-preview support.

The [C#](https://github.com/dotnet/vscode-csharp) extension is installed
automatically.
