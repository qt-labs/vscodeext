# Qt Python Extension for VS Code

This extension helps you develop [Qt for Python](https://doc.qt.io/qtforpython-6/) projects with Visual Studio
Code and Python

## Features

- Build, run and clean PySide6 projects.
- Debug PySide6 applications with debugpy and QML debugger.
- Read PySide6 documentation.
- Provide a command to install PySide6 packages.

## Prerequisites

The [Python extension for Visual Studio Code](https://github.com/Microsoft/vscode-python)

## Quick Start

1. Install the extension.
1. Create a virtual environment or select a Python interpreter from an existing virtual environment.
1. Install PySide6 packages by using one of the following methods:
    - Run 'Qt-Python: Install PySide6' from the Command Palette
    - Manually install PySide6 in the terminal (make sure your desired virtual environment is activated).
1. Open or create a new PySide6 project and start developing.
