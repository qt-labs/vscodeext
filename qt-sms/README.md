# Qt Software Management Service

This extension provides integration with the Qt Software Management Service,
allowing you to search, list, and install Qt packages directly from VS Code.

## Features

- **Search Packages**: Browse available Qt packages
- **List Installed**: View currently installed packages
- **Install Packages**: Install packages with progress tracking

## Configuration

| Setting | Description |
|---|---|
| `qt-sms.serviceExecutablePath` | Path to the `QtSoftwareManagementService` executable |

## Commands

| Command | Description |
|---|---|
| `Qt: SMS: Search available packages` | Search and browse available Qt packages |
| `Qt: SMS: List installed packages` | List currently installed packages |
| `Qt: SMS: Install package` | Pick and install a package |
